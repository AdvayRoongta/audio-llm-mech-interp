# raw/

Source and derived dataset CSVs. Not generated by any `build/` script — these are the
inputs the `build/` scripts read from.

## mustard++_text.csv

Original MUStARD++ text/label export, as published in the upstream
[cfiltnlp/MUStARD_Plus_Plus](https://github.com/cfiltnlp/MUStARD_Plus_Plus) repo (see
`third_party/MPP_Code/README_MUStARD.md` for dataset provenance/citation). Each `SCENE`
groups one labeled target utterance (`KEY` ending in `_u`) with its preceding dialogue
context turns (`KEY` ending in `_c_NN`, unlabeled). Only the `_u` rows carry `Sarcasm`,
`Explicit_Emotion`, `Implicit_Emotion`, `Valence`, `Arousal`.

## mustard_pp_utterances_only.csv

Filtered to the 1201 labeled `_u` rows only (near-balanced 601 sarcastic / 600
non-sarcastic). Regenerate with:

```python
import pandas as pd
df = pd.read_csv('raw/mustard++_text.csv')
u = df[df['KEY'].str.endswith('_u', na=False)].copy()
u.to_csv('raw/mustard_pp_utterances_only.csv', index=False)
```

This is the input consumed by `build/build_sarcasm_pacing_dataset.py` via `--input-csv`.

**Note:** in the filtered file, non-sarcastic (`Sarcasm==0`) rows have
`Explicit_Emotion == Implicit_Emotion` 94.7% of the time — the two only reliably diverge
under sarcasm. `Ridicule` is the one emotion label that appears exclusively in
`Implicit_Emotion`, never in `Explicit_Emotion`.
